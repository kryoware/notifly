# Notifly — The Quiet Fold screen set

Nine individual Android screen concepts generated with built-in imagegen on 2026-09-26, based on the [approved brandkit](../brandkit.png). All displayed financial data and capture counts are fictional. These are visual design references.

| Screen | Purpose |
| --- | --- |
| [Home](01-home.png) | Confirmed balance, separate pending review, recent activity and offline sync. |
| [Transactions](02-transactions.png) | Mixed transaction list with explicit pending and confirmed states. |
| [Review transaction](03-review.png) | Inspect a parsed transaction before deliberately confirming it. |
| [Add transaction](04-add-transaction.png) | Record a manual expense with editable amount, category and date. |
| [Insights](05-insights.png) | Confirmed spending by category, income and monthly net. |
| [Settings](06-settings.png) | Capture, privacy, sync, security and appearance preferences. |
| [Allowed apps](07-allowed-apps.png) | Explicit app allow-list with three enabled and two disabled examples. |
| [Notification log](08-notification-log.png) | Local capture outcomes; an unrecognized amount creates no transaction. |
| [Notification access](09-notification-access.png) | Explain Android special access and offer manual use. |

The main destinations use Home, Transactions, Insights and Settings. Focused forms and capture setup use back/close navigation. Suggested journeys: Home → Transactions → Review transaction; Home → Add transaction; Settings → Allowed apps or Notification log; Notification access → Android settings.

Pending expenses total ₱860.00 (₱180.00 + ₱680.00) and do not alter the ₱24,680.00 confirmed balance. Insights use ₱33,000.00 income less ₱8,320.00 spending. Notification text stays on device; only confirmed transactions may sync.
